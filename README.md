# AlphaLens
AlphaLens — Quant long-short factor strategy engine combining Value, Momentum, Quality &amp; Low-Vol signals into a composite alpha score with EWMA vol targeting, RSI regime neutralisation &amp; Kelly sizing. Backtested 2017–2024: Sharpe 0.415, +3.32% alpha, −7.97% MDD. Interactive Streamlit dashboard included.
